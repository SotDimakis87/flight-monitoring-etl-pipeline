# ✈️ Flight Monitoring ETL Pipeline

## 📌 Project Overview

This project implements an automated ETL (Extract, Transform, Load) pipeline that retrieves real-time flight departure data from the AviationStack API, transforms the data into a structured format, and loads it into a PostgreSQL database running in Docker containers.

The pipeline is scheduled using Cron to automate data collection and build a historical dataset over time.

## 🛠️ Technologies

- Python
- AviationStack API
- Pandas
- PostgreSQL
- Docker
- Docker Compose
- Cron
- SQL
